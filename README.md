# AttendQ front-end demo

Open `index.html` directly or use VS Code Live Server. Sign in with any registration number and password to enter demo mode.

Pages: `index.html` (login), `dashboard.html`, `subjects.html`, `calendar.html`, `calculator.html`, `profile.html`. Shared design is in `styles.css`; navigation, demo data, and interactions are in `app.js`.

Important: This is a front-end prototype. Login is not secure authentication; it only saves demo data in browser localStorage. Records are sample data. A real deployment needs a backend, database, password hashing, session management, and authorization.
